System Architecture

1
Client Request
Receives authenticated POST request containing the x-api-key.
2
MongoDB Auth
Validates key and verifies user has sufficient daily token budget.
3
Redis Rate Limit
Atomic Lua Token-Bucket algorithm prevents race conditions.
4
Async Logging
Proxies to LLM, extracts token usage, and logs to MongoDB in the background.
