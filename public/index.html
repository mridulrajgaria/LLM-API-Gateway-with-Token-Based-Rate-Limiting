LLM API Gateway

v1.0.0 Production

All Systems Operational

A high-performance, token-bucket rate-limited proxy for Large Language Models. Built with Node.js, Express, and Redis to enforce API budgets and asynchronously log usage metrics. 

curl -X POST https://your-domain.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "x-api-key: your_api_key_here" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
⚡ Atomic Rate Limiting
Lua-scripted Redis token-buckets prevent race conditions under load.
🔒 Budget Enforcement
Strict daily and monthly token caps tracked securely in MongoDB.
📊 Async Logging
Usage metrics are aggregated post-response to ensure zero added latency.
